This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Arcade Vault: a platform to play games online and compete for the highest score. The project follows Spec Driven Design (`/spec` and `/spec-impl` workflow) using skills from https://github.com/Klerith/fernando-skills (installed with `npx skills@latest add Klerith/fernando-skills`). The README is written in Spanish.

The codebase is currently the unmodified Create Next App scaffold (`app/layout.tsx`, `app/page.tsx`, `app/globals.css`); there are no tests, API routes, or game logic yet.

## Next.js version caveat

This uses Next.js 16.4.6 / React 19.3 with breaking changes versus common training data. Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`; start at `index.md`). Use the App Router (`app/`).

## Configuration notes

- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. `cacheComponents` changes caching/rendering semantics (opt-in caching with `"use cache"`, dynamic access needs Suspense boundaries) — check the docs before writing data fetching.
- Tailwind CSS v4 is wired through Turbopack via a `turbopack.rules` entry for `*.css` using `@tailwindcss/turbopack` (not PostCSS). Theme tokens are defined in `app/globals.css` with `@theme inline`; dark mode uses `prefers-color-scheme`.
- Root layout uses the global `LayoutProps<"/">` type (generated by Next typegen) rather than a hand-written props type.
- Path alias: `@/*` maps to the repo root.
- `AGENTS.md` is regenerated by `next dev`; leave it as is.
